# Asset attributions

- **Baloo 2, 700 Latin subset** (`assets/fonts/Baloo2-700-latin.woff2`): derived from the [Baloo 2 variable font in Google Fonts](https://github.com/google/fonts/tree/main/ofl/baloo2), copyright 2019 The Baloo 2 Project Authors. Licensed under the SIL Open Font License 1.1; the complete license and copyright notice are in [`assets/fonts/OFL.txt`](assets/fonts/OFL.txt). The file is a local static 700-weight subset containing basic and extended Latin glyphs for Polish and German headings; other scripts use the system fallback.
- **Feedback MP3 files** (`assets/audio/`): original tones generated by [`tools/generate_feedback_audio.py`](tools/generate_feedback_audio.py). No third-party recording is used.
- **Empty-library illustration and inline icons**: original SVG artwork made for this project.
